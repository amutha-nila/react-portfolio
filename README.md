# Nila — React Portfolio

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Build for deployment

```bash
npm run build
```

## Before publishing

Replace:
- `YOUR_EMAIL@example.com`
- GitHub URL
- LinkedIn URL
- Any project details you want to personalize

Then push the project to GitHub and deploy with Vercel.
